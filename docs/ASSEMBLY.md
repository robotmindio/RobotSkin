# RobotMind assembly

## Hardware

Each occupied lock station uses one M3×3×4, 4.0 mm-OD brass heat-set insert
and one M3×6 pan-head screw. The insert is heat-set flush into the 3 mm-deep,
blind centre bore of the plate's female port; it does not pass through the
plate. Its M3 threaded centre remains open for the screw. The join or Grove
plaque only supplies peg guidance and a screw-clearance path.

## Sequence

1. For a permanent joint, heat-set one insert at every marked lock station,
   from the exposed plate face. Alignment-only pegs need no insert.
2. Press the pegs into the matching plate ports.
3. Drive one M3×6 screw through each occupied lock station into its insert.

Each join tile has eight locating pegs but only four lock stations: two on
each attached plate, in the row farthest from the seam or corner. Use all four
for a permanent joint. A full 80 mm edge uses four tiles and 16 stations total
(eight per plate face).
The Grove plaque uses its two lock stations. Press-fit-only assembly remains
removable.
