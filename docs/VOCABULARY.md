# RobotMind vocabulary

- **Dock:** fixed receiver bolted to a robot, wall, plate, or adapter.
- **Carrier:** payload holder with integral male rails.
- **Rail:** one half of the sole RobotMind payload interface.
- **Channel:** matching female rail volume in a dock.
- **Mounting plate:** an M3-fastened base carrying one dock; it is not a
  second payload interface.
